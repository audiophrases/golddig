# Golddig Vertical Slice Implementation Plan

> **For Hermes:** Execute task-by-task with test-first development and separate specification and quality review.

**Goal:** Build and exercise a lightweight Tauri desktop application that searches a real local SQLite fixture pack and renders fast, formatted, text-first dictionary results for American English, Catalan, French, German, and Spanish.

**Architecture:** Svelte/TypeScript renders typed lexical DTOs returned by narrow Tauri commands. Rust owns normalization, SQLite/FTS5 access, ranking, and pack building. The fixture pack is reproducible from authored JSONL and contains provenance for every user-visible fact.

**Tech stack:** Tauri 2, Rust stable, `rusqlite` with bundled SQLite/FTS5, Serde, Svelte 5, TypeScript, Vite, Vitest.

---

## Acceptance criteria

- The Windows desktop application builds and starts.
- Searching a fixture lemma uses the Rust/SQLite query path, not hard-coded frontend data.
- Exact, case-folded, inflected-form, prefix, and language-aware loose lookup are tested.
- Spanish `ñ/n`, Catalan `l·l/ll`, German `ß/ss`, French `œ/oe`, and accent behavior have collision tests.
- A result can contain definition, translation, example, synonym/relation, collocation, form, IPA, and provenance.
- The interface is one-column, semantic formatted text with no result images, source CSS/JavaScript, remote media, or mandatory audio.
- Normal lookup makes no network request.
- Tests, production build, Rust lint/format checks, and a launched-app smoke check pass.
- Startup, exact lookup, prefix lookup, pack size, and time-to-visible-text are measured and recorded as observations, not claims.

## Task 5: Implement normalization using strict TDD

**Files:**
- Create: `src-tauri/src/normalization.rs`
- Test: Rust unit tests in the same module

**Behavior:**
- preserve NFC display text;
- create exact normalized and language-specific loose keys;
- normalize punctuation and whitespace;
- never conflate Spanish `ñ` with `n` in the normal loose tier;
- rank exact forms above loose aliases;
- resolve inflections only from explicit fixture forms.

**Steps for each behavior:**
1. Write one failing test.
2. Run that test and confirm the expected failure.
3. Add the minimum implementation.
4. Run the focused test and full suite.
5. Refactor only while green.
6. Commit.
